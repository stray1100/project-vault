用途与定位

嵌入式开发（STM32F407 主线）44 周 / 308 知识点学习系统的第一批 B1：第 1–14 天覆盖硬件最小系统、工具链、启动流程、时钟树、GPIO 与固件体积，按需深度拆成 7 天深版（约 2400–3500 字）+ 7 天精简版（约 1200–1550 字），单文件 HTML 断网可读。

嵌入式入门最容易卡在「板子不亮但不知道从哪查」：原理图看不懂、工具链三段各自干什么不清楚、启动流程是黑盒、时钟配错只表现为串口乱码。这些不是知识量问题，而是缺一条可观测的因果链。

B1 用 14 天把这条链立起来：第 1 周解决「为什么能跑」——最小系统四要素、交叉编译三段、SWD/JTAG 调试通路、复位向量到 main 的启动流程，再用 D07 复盘压成六个可观测环节；第 2 周解决「跑起来之后怎么控制」——时钟树倍频链、GPIO 输出四种模式、输入上下拉与按键抖动、BSRR 与 ODR 的读改写差异、固件体积与 map 文件读法，D14 用因果链自测收口。

分层不是缩水：7 天深版给到寄存器位与失效现象的可判读细节（约 2400–3500 字），7 天精简版给到够用的操作口径（约 1200–1550 字），按真实可用时间分配注意力，但两天复盘日不打折。

本说明由项目档案馆统一维护，更新项目信息后本页会同步重建。

功能模块

D01–D04 硬件与工具链地基（深版）最小系统四要素（VDD/VDDA/VCAP/VBAT 五路供电、HSI/HSE/LSE 三套时钟、NRST 与复位源状态机、BOOT0 启动映射）、交叉编译三段产物、SWD 与 JTAG 分工、复位向量到 main 的启动流程。
D05–D07 工程骨架与串口（精简版 + 复盘）工程骨架与 CMSIS 头文件来历、printf 重定向与半主机区别；D07 把「写代码到板子上跑」拆成六个可观测环节做整合复盘。
D08–D11 时钟与 GPIO（深版为主）HSE 到 SYSCLK 的 PLL 倍频链与分频树、GPIO 推挽/开漏/速度/上下拉的适用场景、输入抖动与上下拉选型、BSRR 置位复位与 ODR 读改写的原子性差异。
D12–D14 体积、调试与收口size 输出与 map 文件读法（Flash/RAM 占用从哪来）、printf/断点/逻辑分析仪/示波器四层调试手段的分工；D14 用「时钟—引脚—输出」因果链自测。
每日固定三段式每天都有「今日目标（可验收）+ 精讲正文 + 动手三步」，末尾附自测与易错点；深度版额外给寄存器表、失效现象对照与排错判读路径。
移动端单文件离线131KB 单 HTML，内联全部样式与脚本，零外链零请求；390px 宽无横滚，跟随系统深色模式，可加到 iPhone/安卓主屏断网阅读。

  2. ② 打开（电脑）：双击 downloads 里 embedded-learning-b1.zip 解压，得到同名 .html 与 .md 两份 → 预期：HTML 双击即在浏览器打开，MD 可用任意编辑器或 Typora 阅读；不需要 Python、不需要联网。

  4. ④ 按分层强度读：标题下你会看到「精讲分层：深度版（约 3260 字）」或「精简版（约 1550 字）」——深度版给的是可推导的机制链与寄存器级细节（D01–D04、D08、D09、D11 共 7 天），精简版给的是够用即止的操作口径（D05–D07、D10、D12–D14 共 7 天）。时间紧就只读精简版，但深度版的 7 天不建议跳。
  5. ⑤ 每日闭环四步：先读「今日目标」确认能验收 → 读精讲正文（为什么学 / 原理 / 寄存器或工具链细节）→ 按「动手三步」在板子上做一遍（如万用表量 VDD 与 NRST、拨 BOOT0 观察启动差异）→ 用「自测」与「易错点」核对，答不上来就回到对应小节，不要往下翻。

  7. ⑦ 复盘日（D07、D14）：不学新知识点，只做整合复盘——D07 把「写代码到板子上跑」拆成六个可观测环节，D14 走一遍「时钟→引脚→输出」因果链自测；两天的复盘题必须全对再进入下一周。
  8. ⑧ 取完整套件 / 更新：完整套件（HTML + MD）在 https://stray1100.github.io/project-vault/downloads/embedded-learning-b1.zip ；页面右下角「↻」会比对 version.json，落后则自动清缓存并硬重载，一致提示「已最新」。加在主屏的图标下次打开自动升级，不用删掉重加。

常见问题

板子插上调试器却连不上，先查哪？

按 D01 的四要素顺序查，不要先怀疑代码：①量 VDD 与 VDDA 是否有电、VDDA 是否干净；②NRST 是否被按死或复位电容异常；③BOOT0 是否悬空（悬空会导致上电电平不确定，表现成「有时能连有时不能」）；④SWD 的 SWDIO/SWCLK 是否被复用成普通 IO 或未接 GND。四步都正常再查调试器配置。

板子每隔几秒自己重启，怎么定位？

先读 RCC_CSR 的复位标志位，它会告诉你「这次是谁把我复位的」：IWDGRSTF=独立看门狗喂狗超时（任务阻塞或中断长时间屏蔽）、PORRSTF/BORRSTF=供电跌落或纹波过大、PINRSTF=复位线干扰或按键卡死、SFTRSTF=代码主动软复位。读完记得写 RMVF 清标志，否则下次会误判成旧事件。

串口能打印但全是乱码，是时钟配错吗？

大概率是时钟源选错后波特率基准跟着偏。检查是否实际跑在 HSI（内部 RC，室温约 ±1%，全温区更差）而不是 HSE；HSE 起振失败时芯片会自动退回 HSI 继续跑，板子看似正常但通信全错帧。用 D08 的倍频链逐级核对 SYSCLK/APB1/APB2 与 USART 时钟，再算 BRR。

深度版和精简版差别在哪，可以只读精简版吗？

深度版 7 天（D01–D04、D08、D09、D11）给到寄存器位、失效现象与排错判读路径，是后面所有实验的地基；精简版 7 天（D05–D07、D10、D12–D14）给到够用的操作口径。时间紧可以只读精简版，但深度版那 7 天不建议跳，尤其 D08 时钟树与 D11 BSRR。
