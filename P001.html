用途与定位

把本 APP 内创作的所有项目登记成册，按序号调阅，每个项目配一份 HTML 使用说明。

跨会话的「作品登记簿」：把每次做出来的东西按编号存档，附一份手机能直接打开的说明书，避免下次只会说「之前好像做过」却不记得在哪。

projects.json 是唯一事实来源，说明书页全部由它渲染，不手写 HTML；登记新项目或修正路径后重建即可。

本说明由项目档案馆统一维护，更新项目信息后本页会同步重建。

功能模块

登记 add写入名称、类型、摘要、关键技术、产物绝对路径、使用方式与注意事项，自动分配编号并生成说明页。
清单 index重建 guides/INDEX.html 总览页，按编号列出全部项目、类型、产物数量与说明页路径。
调阅 show报编号即输出该项目的完整说明书内容，省去翻记录。
更新 update修正路径、补充使用方式或追加版本记录后自动重新渲染对应说明页。
渲染 render生成自包含单文件 HTML：内联 CSS、viewport 适配、深浅色自动切换、无外链，手机离线可看。
回溯补录项目未及时登记时，可从历史会话产物路径反查后补录，不靠记忆编造。

使用方式

  1. 首次使用：确认 skill 目录下存在 projects.json 与 guides/ 目录。
  2. 登记项目：提供名称、类型、摘要、产物绝对路径；写明使用方式与注意事项。
  3. 生成说明：执行 render 重建对应 P00x.html，再执行 index 重建总览页。
  4. 忘记编号：先 list 看清单，再按编号 show 调阅。
  5. 路径变动：update 修正后重建，避免说明书指向失效路径。
  6. 手机查看：直接把 guides/P00x.html 或 INDEX.html 传到手机打开，无需联网。
  7. 线上查看：手机浏览器打开站点网址，即为最新版说明书，可「添加到主屏幕」当 App 用。

边界与限制

  • 说明页由 projects.json 驱动，直接手改 HTML 会在下次重建时被覆盖。
  • 只登记路径与用法，不保存产物文件本体，原文件被移动或删除需同步 update。
  • 新增说明页后需重建 INDEX，否则总览看不到新条目。

常见问题

换电脑后还能用吗？

把整个 project-vault 目录（含 projects.json 与 guides）复制到新机器同一位置即可，路径迁移后需 update 修正。

怎么新增一个项目？

提供名称、类型、摘要、产物绝对路径三项核心信息即可登记，其余字段可后补。

说明书为什么不是手写 HTML？

手写会与登记信息脱节；统一由模板渲染，改一次数据所有页面同步。
