使用方式

  1. 第 1 步 · 让技能进入技能池：右键任务栏右下角托盘里的 Marvis 图标 → 选「退出」（只关闭窗口无效）→ 重新打开 Marvis → 在任意会话发送「我的技能」。预期看到 5 条：huashu-nuwa、darwin-skill、huashu-design、huashu-art-motion、huashu-mac-use。若列表里没有：说明 skills\custom\<名字>\SKILL.md 不在或 data.db 的 skill_index 缺 custom 记录，直接跳到第 8 步排查。
  2. 第 2 步 · 验证「女娲」（把一个人的思维蒸馏成 skill）：发送「女娲，把查理·芒格的思维蒸馏成 skill」。预期按 3 段回显：①调研提纲与信息来源清单 ②心智模型 / 决策规则清单 ③在 skills\custom\munger-thinking\ 下生成 SKILL.md。通过标准是磁盘上真的出现该文件；如果只在对话框里贴了一段文字、没有建目录，说明 skill 没被加载，重发「用 nuwa 技能，把芒格的思维蒸馏成 skill」。
  3. 第 3 步 · 验证「达尔文」（给已有 skill 打分）：发送「达尔文，给 huashu-design 打分」。预期输出三段评分表——结构维度（满分 59）、效果维度（满分 35）、meta 维度（满分 6），外加 top3 改进项与具体改法；改完再跑一次可对比分数前后变化。
  4. 第 4 步 · 验证「Design」（HTML 视觉设计）：发送「用 design 做三个方向的封面初稿，主题：科室质控汇报」。预期先在 temp 目录产出 3 份独立 HTML 初稿，并各配一句话说明风格差异，等你选定方向后再细化，不会直接吐一版终稿。首次运行若报 playwright 找不到浏览器，先按第 6 步装 chromium，然后原话重发。
  5. 第 5 步 · 验证「Art-Motion」（视频分镜 / 动效）：发送「用 art-motion 出 30 秒镜头表，主题：高血压如何伤肾」。预期输出逐镜头表（镜号 / 时长 / 画面 / 字幕 / 音效）并自动调用 storyboard_lint.py 自检，红灯数为 0 才进入下一环节；报 ffmpeg 相关错误时按第 6 步补装。
  6. 第 6 步 · 补运行依赖（只在报错时做）：打开 PowerShell，cd 到 %APPDATA%\Tencent\Marvis\User\<用户ID>\skills\custom\huashu-design，执行 npx playwright install chromium（约 130 MB；下载超时就先设 $env:PLAYWRIGHT_DOWNLOAD_HOST="https://npmmirror.com/mirrors/playwright" 再重跑）；再执行 winget install --id Gyan.FFmpeg -e 装 ffmpeg，装完新开一个终端用 ffmpeg -version 确认有版本号输出。git 与 uv 已装好，无需再装。
  7. 第 7 步 · 日常怎么用：不需要写全名，说「用 design 画一张…」「用 art-motion 排一段…」「让达尔文评审这个 skill」就会命中；同一会话内可连续调用，跨会话重启后依然可用。想确认当前是否加载：发送「我的技能」看列表即可。
  8. 第 8 步 · 排错：技能不生效按顺序查三处——①目录是否存在：dir skills\custom\<名字>，必须有 SKILL.md；②库内是否有记录：在 PowerShell 里跑 python -c "import sqlite3,os;p=os.path.expandvars(r'%APPDATA%\Tencent\Marvis\User\<用户ID>\data.db');print(sqlite3.connect(p).execute(\"select name,version from skill_index where source='custom'\").fetchall())"，能看到 5 条才对；③改库前必须先把 data.db 复制成 data.db.bak-<时间戳>（已有的备份为 data.db.bak-20261022123819），改完必须重启客户端，运行期不热更新。
  9. 第 9 步 · 更新：cd 进 skills\custom\<名字> 后执行 git pull（git 已配置 gh-proxy.com 镜像重写，直连 GitHub 失败也会自动走镜像），或从 GitHub 下载 archive zip 解压覆盖同名目录；更新后关闭 Marvis 再打开才生效。
