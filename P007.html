用途与定位

按 123 天计划推进 102 个生理学知识点的每日学习助手，内置 15 篇精讲与间隔重复排程，单文件离线可用，已上线 GitHub Pages 并可加到 iPhone 主屏。

使用方式

  1. 电脑：双击「打开预览.bat」或直接双击 生理学每日学习助手-移动版.html，浏览器打开即可，无需联网。
  2. iPhone：Safari 打开 https://stray1100.github.io/physiology-daily/ → 底部「分享」→「添加到主屏幕」。微信内置浏览器不支持添加主屏。
  3. 每天打开先看「今日」页的知识点与复习提醒，做完勾选完成；再进「答题」复习到期卡片；遇到易错点在「制卡」里沉淀。
  4. 换设备或清缓存前，先到「统计」页导出 JSON 备份，在新设备同页导入恢复。
  5. 本地不给手机联网时，可在 生理学每日学习助手移动版 目录执行 python -m http.server 8000，手机连同一 WiFi 打开 http://电脑IP:8000/生理学每日学习助手-移动版.html。
