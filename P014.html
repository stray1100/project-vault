用途与定位

面向内科住培与门急诊一线的红旗征识别系统：同一套 72 个知识点、12 周 / 84 天节奏（每周 6 个新点 + 1 天复盘，每 4 周 1 次月模考），按教材主线与批注口径拆成甲（诊断学+实用内科学）、乙（急诊与灾难医学）、丙（诊断学+基层指南+NICE NG12）三版；单文件 HTML 完全离线，含日期切换与「回到今天」防误打卡提示条。

红旗征的难点不在背条目，而在「什么时候该停下来排查致命病因」。规培与门急诊场景下要的东西并不一样：查房汇报要完整推理链，夜班首诊要几分钟内的处置顺序，社区门诊要「本院查不了时按什么标准上转」。同一套知识点换三种口径写，比背三本书现实。

本系统用 72 个知识点覆盖 12 周：第 1–4 周打判别总论与床旁方法（红旗阈值、休克四型、意识与呼吸评估），第 5–8 周进胸痛/呼吸/消化/感染四条主线，第 9–12 周收神经急症、内分泌代谢与肾脏、血液肿瘤风湿与特殊人群；每周 6 个新点 + 1 天复盘，每 4 周一次月模考。

三版的路由按场景而非水平：甲走诊断学与实用内科学的完整判据与鉴别链；乙把判据压到能立刻改变处置的那几条，给时间轴与「谁先上」；丙在判据之后强制补一句上转阈值与安全网交代。卡片内并列另两版写法，同一张卡就能看到三种口径的差别。

本说明由项目档案馆统一维护，更新项目信息后本页会同步重建。

功能模块

72 点同源 · 三口径并行三版共用同一套 72 个知识点与同一份 84 天排期（2026-11-02 → 2027-01-24，9 个复盘日 + 3 次月模考，A 级 56 / B 级 16），每张卡片标注「本版口径」并并列显示另两版写法，切换成本只是换文件。
每日闭环 + 三项打卡卡片固定六段（为什么必须记住 / 判据 / 边界 / 动作 / 必背要点 / 最常见的坑），底部 3 题含 1 道陷阱题；精读、练习、口头复述三项全勾才记当天完成，答错点「没答上」自动进错题并记录复习次数与最近日期。
日期切换与「回到今天」防误打卡今日页支持 ‹ / › 与日期框回看与预习；非当天时底部常驻提示条，明示「正在看第 N 天，今天实际第 M 天，打卡会记在第 N 天」，点「回到今天」立刻归位并隐藏提示条，切页签自动隐藏、回到今日页重新出现。
五个页签与全文搜索今日（打卡）/ 计划（84 天全表按模块与周查看）/ 卡片（72 张全文 + 搜索 + 收藏）/ 错题（重做与标记已掌握）/ 我的（导出导入与重置）；搜索支持按主诉或征象直接命中。
完全离线的单文件每版单 HTML 约 283–284KB，内联全部样式与脚本，零外链零请求；360 / 390 / 412px 三档宽度实测无横向滚动、无 JS 报错，可加到手机主屏断网阅读。
数据隔离与可迁移三版分别用 rf:v1:A / B / C 存储，互不覆盖，可同时安装；进度、错题、收藏、起始日期可导出为 JSON，换文件或换设备后导入继承（不同文件名属不同存储域，必须走导入导出）。

使用方式

  1. ① 选一版：内科规培在岗、要写病程与查房汇报选甲（诊断学第10版 + 实用内科学第16版，单点精读 25–35 分钟）；急诊/ICU 轮转、夜班首诊选乙（急诊与灾难医学第4版，判据压到「几分钟内先做什么」）；社区/门诊独立出诊选丙（诊断学第10版 + 中华医学会基层指南 + NICE NG12，落到「识别—稳住—上转」）。三版知识点同源，可先跑甲打底，按轮转月切乙或丙。
  2. ② 打开（手机）：Safari 打开 https://stray1100.github.io/project-vault/tools/redflag-a-internal-medicine.html → 预期：深色学习页，顶部显示「第 N 天 / 84」，下方是今日模块与当天那 1 张精读卡片入口；点「分享 → 添加到主屏幕」后断网点开仍可用。菜单里没有该选项说明是 file:// 打开的，换 https 地址重开。
  3. ③ 打开（电脑）：直接打开对应工具页，或下载 https://stray1100.github.io/project-vault/downloads/redflag-aid-3ver.zip 解压 → 预期：三套目录各自含 HTML、使用说明、知识点卡速查、计划总表 CSV，外加一份《三版对照与选择指南》；HTML 双击即在浏览器打开，不需要 Python、不需要联网。
  4. ④ 每日闭环（15–30 分钟）：打开「今日」→ 按「为什么必须记住 → 判据 → 边界 → 动作 → 必背要点 → 最常见的坑」读卡片 → 做底部 3 题（含 1 道陷阱题，先自答再点开答案）→ 勾三项打卡（精读卡片 / 完成练习 / 口头复述或写一句病例）。三项全勾当天才算完成；答错的题点「没答上」自动进错题页。
  5. ⑤ 切换日期与「回到今天」：今日页标题下方有 ‹ / › 与日期框，可回看已过内容或提前预习；翻到非今天时，页面底部常驻一条提示条，写明「正在看第 N 天 · 日期」并提示「今天实际第 M 天，打卡会记在第 N 天」。此时勾选会记在正在看的那一天——预习完或回看完，先点提示条上的「回到今天」再打卡，避免把进度记到别的日子；切到其它页签时提示条自动隐藏，回到今日页若仍在非今天状态会重新出现。
  6. ⑥ 五个页签的分工：今日=每天先看这里打卡；计划=84 天全表按模块/周查看，周日看下一周并提前想好要用的病例；卡片=72 张全文 + 搜索 + 收藏，写病程前或值夜班前扫模块；错题=每次复盘日重做一遍，可标记已掌握；我的=导出/导入与重置。搜索框输主诉或征象（如「胸痛」「意识」「血钙」）可直接命中，比翻模块快。
  7. ⑦ 周复盘与月模考：第 7、14、21…天（周日）是复盘日，不学新点——闭卷写出本周 6 个点的「判据 → 边界 → 动作」，重做本周错题，再用 1 个真实病例把 6 个点串一遍；第 28、56、84 天为月模考，从本月 24 个点里随机抽至多 20 题自评，正确率低于 80% 的模块回卡片页重刷。模考是自评工具，答错不进任何记录。
  8. ⑧ 备份与换版：「我的 → 导出」下载 JSON（勾选、错题、收藏、进度、起始日期）。换文件、换设备、清缓存前先导出，进新文件后在「我的 → 导入」选回。注意不同文件名在部分手机浏览器属不同存储域，直接换文件不会继承旧进度，必须走导出/导入；「重置」清空全部记录且不可撤销。
  9. ⑨ 边界：本工具是学习与复述工具，不是临床决策系统。阈值与路径以所在医院现行制度与最新版指南为准；指南层共用 NICE NG12（2026-04 更新）、SSC 2025（不再推荐 qSOFA 作为单一筛查工具）、NICE NG51 / NG128 / NG59，教材与指南更新后回原文核对。

常见问题

甲、乙、丙三版该选哪个？

按场景选，不按水平：内科规培在岗、要写病程与查房汇报用甲；急诊/ICU 轮转、夜班首诊用乙；社区或门诊独立出诊、检查手段有限用丙。还没定方向就先跑甲打底，轮转月切乙或丙——知识点同源，切换只是换一个 HTML。

翻到别的日期后打卡，进度记在哪一天？

记在你正在看的那一天，不是今天。所以翻到非当天时页面底部会出现常驻提示条，写明「正在看第 N 天 · 日期」以及「今天实际第 M 天，打卡会记在第 N 天」。预习或回看结束后，点提示条上的「回到今天」再打卡即可。

换新文件后进度没了，能找回吗？

先看是否导出过 JSON。「我的 → 导出」会下载含勾选、错题、收藏、进度与起始日期的备份，进新文件后「我的 → 导入」选回即可。不同文件名在部分手机浏览器属于不同存储域，直接替换文件不会继承旧数据；没导出过则无法恢复。

三项打卡只勾一项算完成吗？

不算。精读卡片、完成练习、口头复述或写一句病例三项全勾才记当天完成，这是为了避免「只是翻了一遍」被记成学会。答错的题点「没答上」会进错题页，复盘日集中重做。

手机上能离线用吗？需要联网吗？

能。直接打开线上地址，或把 zip 解压后把 HTML 传到手机；页面零外链、零请求，加到主屏后断网可读。三版可同时装，进度各自独立保存。
