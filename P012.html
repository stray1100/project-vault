用途与定位

四套并行的摄影每日学习系统：同一副骨架（任务卡—交付物—三维评分—间隔复现），按可投入时间分成 105 / 84 / 56 / 28 天四档；可加到 iPhone 主屏断网使用，配套 Python 脚本做当日任务与进度统计。

摄影入门的瓶颈通常不是器材，而是练习没有结构：看了一堆教程，手上的变量却同时改三四个，结果既不知道哪一步起了作用，也无法复现。

这四套系统共用同一副骨架：每天只动一个变量（单变量原则）→ 必须在当天交出可评判的实拍结果（交付物驱动）→ 用技术/构图/表达三维自评定位问题 → 按 D1/D3/D7/D14/D30 间隔复现，把短期记忆压成长期技能。

四套的差别只在投入强度与教材主轴：天数、每日常识点数、单位时间练习密度不同，骨架不打折。这样你可以按真实可用时间选一套长期跑完，而不是开了四套各跑两周。

本说明由项目档案馆统一维护，更新项目信息后本页会同步重建。

功能模块

甲·学院标准（105 天 / 90 知识点）教材主轴：美国摄影教程（12 版）+ 理解曝光（4 版）+ 用光教程（5 版）+ 摄影师的视界。技术地基最厚，适合想把曝光、用光、视觉语言一次打通的长期路线。
乙·经典强化（84 天 / 72 知识点）教材主轴：纽约摄影学院教程 + 理解曝光 + 摄影构图学。经典体系 + 强构图训练，天数压缩但对成片质量要求更高。
丙·轻量实用（56 天 / 48 知识点）教材主轴：新摄影笔记 + 理解曝光 + 摄影师的视界。轻量化、上手快，优先解决「拍得清楚、拍得好看」。
简易·人像与人文街拍（28 天 / 24 知识点）只覆盖人像 12 点 + 街拍 12 点，C 类实操型、表达权重高，不绑教材。适合先把最常拍的两种题材拍明白。
任务卡四段结构每天固定输出四段：设定（今天只改哪个变量）、交付（拍多少、交几张）、三维评分（技术/构图/表达各 1–5 分）、失败样本（废片失败原因 + 下次修正参数）。
间隔复现排程计划总表 18 列里已排好 D1/D3/D7/D14/D30 复现日；复现日不看笔记、凭记忆重述并重拍，错处回原单元。
移动端 + 本地脚本双端手机用单文件 HTML（可加主屏、断网可跑）；电脑用 study_assistant.py + 4 个 bat 跑今日任务、自评、卡片与统计。

使用方式

  1. ① 选一套：可用时间 ≥1.5 h/天选甲（105 天 / 90 知识点）；1 h/天选乙（84 天 / 72 点）；40 min/天选丙（56 天 / 48 点）；只想先把人像和街拍拍明白选简易（28 天 / 24 点）。四套不要同时开，单变量推进才有对照。
  2. ② 打开（手机）：Safari 打开本项目 site 字段的线上地址 → 预期：深色学习页，顶部显示「第 N 天 / 总天数」，下面是当日任务卡；四套各有独立入口（见 notes 中的四个链接）。加到主屏：底部「分享」→「添加到主屏幕」→ 断网点开仍可用。若菜单里没有该选项，说明是 file:// 打开的，换 https 地址重开。
  3. ③ 打开（电脑）：解压 downloads 里对应 zip → 双击「1-今日任务.bat」→ 预期：控制台打印当日单元、教材页码、拍摄任务、交付物清单与三维评分点；照做后双击「2-答题自评.bat」录分。
  4. ④ 每日闭环：任务卡四段 ——（a）设定：今天只练一个变量（如仅改快门，光圈 ISO 固定）；（b）交付：实拍 20–30 张，选出 3 张成片；（c）三维评分：技术（曝光/对焦/噪点）、构图（主体/取舍/引导）、表达（是否传达意图），各 1–5 分；（d）失败样本：写下 1 张废片的具体失败原因与下次修正参数。
  5. ⑤ 间隔复现：计划表已排好 D1 / D3 / D7 / D14 / D30 复现日。到复现日只做一件事：不看笔记，凭记忆重述要点 + 重拍一张同题；错的地方回到原单元，不新开知识点。
  6. ⑥ 看卡片 / 查统计：双击「3-看卡片.bat」随机抽当日知识点卡片自测；「4-查看统计.bat」看累计天数、三维均分走势、各题材点数分布。手机端进度存本机 localStorage，换浏览器或清站点数据会丢。
  7. ⑦ 下载完整套件（含 CSV / materials.json / py / bat / 说明）：手机或电脑打开「downloads」目录下对应 zip（见 notes 中四个直链），解压即可用，无需联网。
  8. ⑧ 更新：线上页面右下角「↻」比对 version.json，落后则自动清缓存并硬重载；一致提示「已最新」。加在主屏的图标下次打开自动升级，不用删掉重加。

边界与限制

  • 评分是自评，主观偏差不可避免；同一张成片建议隔 24 h 再评一次，两次差值 >1 分说明标准还没稳定。
  • 教材页码按所列版次（如美国摄影教程 12 版、理解曝光 4 版）标注，换版次后页码会偏，按章节标题定位。
  • 精讲为自编要点，只引用教材页码与标题，不含教材原文；不能替代教材本身。
  • 进度只存本机 localStorage（网页端）或本地文件（脚本端），不做云端同步；换设备需手动迁移。
  • 四套不含完整的后期调色与商业修图流程，只覆盖拍摄决策与构图表达。
  • 简易方案不绑教材、点位少，适合快速上手，不构成体系化摄影教育。

常见问题

四套要一起练吗？

不要。单变量原则是效率杠杆：同时开两套等于同时改多个变量，无法归因。按可用时间选一套跑完，再考虑换主干。

手机上打开是空白或样式错乱？

多半是 file:// 打开或缓存旧版。改用 https 线上地址，点右下角「↻」强制比对版本；仍异常就清一次站点数据再开。

进度丢了怎么办？

网页端进度存 localStorage，清站点数据、换浏览器、无痕模式都会丢；重要进度请用电脑端脚本（进度写在本地文件）或定期导出 CSV。

必须买教材吗？

甲/乙/丙按教材页码排程，没有书会失去精确定位，但可按章节标题在图书馆或借阅本对照；简易方案不绑教材，可先用它验证自己能不能坚持。

为什么每天要写失败样本？

失败样本是唯一能把「感觉不对」转成「参数不对」的环节；只记成功片会让下次重复同样的错误。
