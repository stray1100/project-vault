用途与定位

规培期间按日推送内科学习内容的离线 PWA，可部署为长期站点并添加到手机主屏。

面向内科方向住院医师规培的在职学习工具，把 716 天学习计划与 233 张卡片全部内嵌进单页，四个视图：今日、答题、制卡、统计。

设计目标是最低启动成本：打开就看到今天该复习什么，答完自动记录，断网、飞行模式下依旧可刷。

本说明由项目档案馆统一维护，更新项目信息后本页会同步重建。

功能模块

今日今日到期复习、逾期未完成清单、开始一轮答题入口、按今日知识点生成骨架卡、手动制卡、卡片库。
答题逐题作答与即时判定，答完给本场小结（对错、用时、待补卡）。
制卡按今日知识点一键生成骨架卡（填空/问答结构），也可手动新建；卡片库可检索与编辑。
统计总正确率、忘记/模糊 Top10、近 30 天学习热力，用于考前定位薄弱点。
数据管理进度 JSON 复制/导出、导入恢复、清空本机数据。
离线Service Worker 预缓存应用外壳（7 条），飞行模式可打开与答题。
自检地址后加 ?selftest=1 跑 26 项自检，用于部署后验证环境。

使用方式

  1. 解压 zip，得到 index.html、manifest.json、sw.js、icons/ 与两份说明文档。
  2. 上传整个目录到 HTTPS 静态托管：GitHub Pages 走 Settings → Pages → main → /(root)；或用 Netlify Drop 拖整个文件夹。
  3. 记下拿到的 https 地址，这就是后续唯一入口。
  4. 手机安装：iPhone 用 Safari 打开 → 分享 → 添加到主屏幕；Android 用 Chrome → 安装应用。
  5. 每日：打开「今日」清掉到期复习，点「开始一轮答题」。
  6. 答错或模糊的题，当日到「制卡」用骨架卡补上，别攒。
  7. 考前看「统计」的正确率与忘记 Top10，优先补高频遗忘项。
  8. 换机或换域名前：统计 → 数据管理 → 复制进度 JSON 另存，新环境再导入。

边界与限制

  • 必须 HTTPS 或 localhost：iOS 只在安全上下文启用 Service Worker / PWA 安装；局域网 http://192.168.x.x 只能当快捷方式，不能离线。
  • 必须整目录上传（index.html、manifest.json、sw.js、icons/），只传 index.html 会丢图标与离线能力。
  • 数据只在本机浏览器 localStorage（键前缀 nkyx.），换网址、换手机、清 Safari 数据都会读不到旧进度。
  • 更新内容需替换 index.html 并递增 sw.js 版本号，否则手机沿用旧缓存。
  • 实测为桌面 Chromium 的移动视口仿真，不等同 iOS Safari 真机验证。

常见问题

打开白屏或断网打不开？

检查三件事：是否 https/localhost、是否整目录上传、Service Worker 是否 activated（可在 ?selftest=1 查看）。

进度丢了能找回吗？

换域名或清过浏览器数据即读不到。此前若导出过进度 JSON，可在数据管理里导入恢复。

更新后还是旧界面？

改 sw.js 里的版本号（当前 nkyx-pwa-v1.0.0）后重新部署，再在手机上重启一次应用。

能多台设备同步吗？

不能，无账号体系。靠导出/导入进度 JSON 手动搬。
