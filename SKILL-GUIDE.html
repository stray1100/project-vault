项目档案馆 Project Vault

登记你在 Marvis 里做过的每一个项目，按序号随时调阅对应的 HTML 说明书。

它能做什么

  • 把散落在各个会话里的项目，统一登记成一份带编号的清单。
  • 每个项目配一份自包含 HTML 使用说明，手机、电脑都能直接看。
  • 唤出即出清单，报序号即出说明，不用翻聊天记录。
  • 支持从历史会话中扫描已落盘的产物并补录。

四步上手

1唤出说 我的项目 或 项目列表，返回带序号清单。
2选择回复 3 或 第 3 个，给出该项目 HTML 说明书。
3登记说 记录新项目：名称 + 路径，自动入库并生成说明书。
4补录说 扫描历史项目，从旧会话抽取产物补进清单。

数据放在哪

全部位于技能目录内，换会话不丢，可整体备份。

  • 项目库：skills\custom\project-vault\projects.json
  • 说明书：skills\custom\project-vault\guides\P001.html …
  • 数据脚本：skills\custom\project-vault\scripts\vault.py
  • 技能说明：skills\custom\project-vault\SKILL.md

    说明书里有什么

    1. 基本信息：编号、类型、创建日期、技术栈、最后更新。
    2. 用途：这个项目解决什么问题。
    3. 使用方式：逐条可照做的启动步骤。
    4. 关键路径与产物：真实落盘的位置。
    5. 注意事项与版本记录。

    注意事项

    只登记真实存在、可访问的产物路径。仅口头设想、未落盘的内容不进入项目库，避免清单失真。

    • 序号随清单顺序变化，跨会话后请以最新清单为准；内部编号 P001 才是稳定标识。
    • 更新项目会重建说明书，旧版保留为 .bak-时间戳.html，可回溯。
    • 删除项目库文件等于清空档案馆，操作前建议先备份。
